# The shell fetches weather, GitHub activity and lyrics over the network at startup. A CI
# container has no internet, and even here the weather API returns 503 often enough to have
# failed 5 of 12 runs in one sitting. A boot gate must not depend on someone else's uptime.
#
# This does hide a genuinely malformed request, so if a feature that talks to the network
# stops working, read the log with this file emptied before believing the gate.
